# 0.1.3 终端复制与粘贴

在 AIO 启动的 CLI 终端面板上增加「复制终端选区」和「粘贴到终端」。两个按钮调用 VS Code 的终端命令，沿用用户的终端设置和多行粘贴确认。切换到其他终端时隐藏 AIO 按钮。

工作台内嵌终端使用 xterm 的选区和粘贴处理。常规 Ctrl+C 仍由 CLI 接收；终端内的复制粘贴组合键与对话编辑区分开处理。

本次将「每次提交新增一份执行总结」写入项目规则，并将用户新增要求归档。

自动测试共 16 项，通过终端命令路由、工作台剪贴板快捷键和 Windows PTY 回归检查。内嵌 xterm 另在真实 Webview 中验证了复制、粘贴事件的数据流。该检查使用浏览器事件，未覆盖工作台内所有系统右键菜单操作。

Windows VS Code 实测中，鼠标拖选终端输出后，标题栏复制按钮将选区写入系统剪贴板。从外部粘贴中文后，测试 CLI 在按下 Enter 前保持等待，按下后收到文本原值。真实剪贴板验收通过环境变量 `AIO_TEST_CLIPBOARD=1` 显式启用。
