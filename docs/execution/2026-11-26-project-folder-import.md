# 0.1.7 文件夹只导入 AIO 项目库

在工作台左侧项目栏或 VS Code 的 AIO 导入节点投放文件夹，可将目录加入项目列表。Explorer 右键「在 AIO 中添加项目」和原生投放节点共用导入实现。工作台拖放只接受当前工作区内的目录，原生入口可接收用户选定的工作区外目录。导入不调用 VS Code 的工作区切换 API。

27 项自动测试通过。安装 VSIX 后，在隔离的 VS Code 中通过原生导入命令加入目录「导入 项目」；AIO 项目数从 1 增加到 2，VS Code 的 workspaceFolders 在操作前后完全一致。直接跨 Webview 拖放的宿主限制与 0.1.5 相同。
