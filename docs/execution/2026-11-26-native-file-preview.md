# 0.1.13 原生文件预览分组显隐

在一个文件分组旁打开 AIO 后，先保持两组并排 2 秒，再根据交互状态最大化工作台。文件标签和编辑内容保留在原生编辑器中。「文件预览」入口恢复原布局，正在编辑文件时保持展开。复杂布局和用户新建的分组不参与自动调整。

Windows x64 使用只读辅助进程判断指针是否位于当前前台 VS Code 窗口的文件分组，只向扩展报告区域状态。工作台关闭时结束观察，不记录输入内容。

两秒从 React 工作台及「文件预览」入口挂载后的首次就绪消息开始。真实 VS Code 1.97 验收初始并排、收起、悬停恢复、文件内容与标签保留、文件编辑焦点独立，以及三分组的数量和顺序保持不变。本机该次测试实际释放宽度为 427 像素。自动测试另检查计时边界和禁用自动布局的条件。
