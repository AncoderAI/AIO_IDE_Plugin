# 0.1.8 点击 AIO 项目切换 VS Code 文件夹

单击工作台项目名称时，扩展从 AIO 服务重新核对已登记的项目根目录，再请求 VS Code 在当前窗口打开它。展开历史、Ctrl 多选、拖放导入以及自动恢复不触发文件夹切换。

切换时一次性交接当前 AIO 项目清单。目标工作区启动后重开工作台并恢复该清单，各工作区继续使用自己的会话存储。已经是当前目录时不重载窗口。

安装 0.1.8 后，在同一 VS Code 窗口真实点击「项目 B」，再点击「项目 A」。独立测试扩展记录的工作区启动顺序恰为 A → B → A。每次切换后工作台都自动恢复，两个项目都在列表中，没有额外重载；之前导入 B 的操作没有切换文件夹。Windows x64 实测通过。
