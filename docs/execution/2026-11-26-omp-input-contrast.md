# 0.1.6 OMP 输入文字对比度

工作台内嵌 xterm 的最低文字对比度设为 4.5。终端程序即使明确输出黑色文字，渲染器也会依据当前背景提高对比度。构建脚本和已分发的终端组件使用同一个参数。本次只更新已分发组件的该项配置，避免引入上游工作树的其他未提交修改。

使用真实 Edge 和 xterm 渲染黑色 ANSI 输入，在工作台深色背景 `#111110` 上测得文字颜色为 `rgb(135, 135, 135)`，对比度为 5.26。复查命令为 `node test-host-ui/verify-contrast.cjs`。

原生集成终端在启动 OMP 时按 VS Code 当前明暗主题设置子进程的 `COLORFGBG`。深色为 `15;0`，浅色为 `0;15`。使用本机 OMP 19.2.1 和 ConPTY，在深色背景响应下实际输入文本，捕获到 OMP 为其输出的前景色为 RGB(229, 229, 231)。未发送模型请求，也未修改用户的 OMP 配置。
