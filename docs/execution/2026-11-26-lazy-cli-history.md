# 0.1.24 按项目和 CLI 加载历史

每个项目固定显示 OMP、Claude Code 和 Codex 三个历史入口。工作台启动和常规项目浏览用轻量项目目录，旧渲染器的自动历史请求在宿主入口返回空。点击加载时才查询该项目和 CLI 的历史目录或索引。恢复命令只受理已在相同项目和 CLI 中加载的条目，使用原生 CLI 在集成终端继续会话。

真实 VS Code 1.97 使用临时 Codex SQLite 索引，通过三入口和点击加载验收。宿主与真实 SQLite 的定向测试记录冷启动零历史读取、点击后仅 A 项目的 Codex 有两次元数据操作，B 和其他 CLI 均为零。OMP 与 Claude 的目录夹具验证按项目分桶及恢复参数。本版 Codex 入口依赖本机的 state SQLite 索引，列表最多显示 100 条。真实账号的历史恢复未执行。

同时保留前一项已完成的 OMP 构建修正，生成脚本解析配置文件时直接使用 Node 路径模块。
