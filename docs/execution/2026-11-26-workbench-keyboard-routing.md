# 0.1.10 工作台终端键盘焦点

目标是在工作台打开 CLI 时，用真实焦点将键盘交给当前终端。点击 AIO 普通工作区后，终端应接收文本和导航键；主动点底部对话框或离开工作台时，键盘应由用户选择的控件接收。鼠标悬停不能激活终端。

真实 Windows VS Code + ConPTY 验收中，命令行夹具记录了 `/x`、Esc、左方向键和 Shift+Tab。点底部对话框后文字只进入草稿。点外侧编辑器，随后把指针悬停到 AIO 上，连续输入仍写入并保存到测试文件，终端按键日志没有新增。

在 VS Code 1.97 的组合验收中，两个终端标签切换后的焦点、菜单展开时的方向键和 Esc 也通过。36 项自动测试通过。1.147 单独通过外部编辑器与悬停检查，最终组合复跑在创建测试窗口时超时。
