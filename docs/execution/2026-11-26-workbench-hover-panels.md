# 0.1.12 工作台左右侧栏悬停显隐

左右栏采用浮层布局，隐藏时透明并释放宽度。左侧项目栏首次显示 4 秒；若指针仍在栏内，则等离开后再收起。右侧检查器在右缘唤出。聊天输入框和内嵌终端区域不作为悬停触发区。

窄屏时保留中间区域的退出空隙，避免浮层盖住整块工作台后难以移出。透明边缘不接收鼠标点击，侧栏显隐由指针所在区域决定；键盘导航仍能通过可聚焦入口进入面板。

真实 VS Code 验收通过了启动计时、左右侧栏的悬停与移出、焦点保留和宽度测量。在宽 532 像素的测试工作台中，中间可用宽度为 532 像素。使用两侧贴边的聊天和终端输入区夹具，确认悬停不会开栏，点击均到达原输入控件。全套 38 项自动测试通过。
