32. 这一段加在中英文的前面：为什么大型软件项目，还需要随时看代码？\
对于中小型软件，可以不读代码，只需要执行测试验证就可以上线。大型软件项目，如果全凭AIcoding生成代码，最后的架构混乱，无法维护。\
1.openclaw这个软件的开发者在访谈中说基本不读代码，导致最后50多万行难以维护，已经是前车之鉴。\
原因是codex这种客户端，只能在对话框输入任务要求，不需要选择或者指定具体函数、代码段、文件、文件夹，作为上下文，AI自动就能准确定位出需要修改的位置，因此只能开发中小型软件这种复杂度低的软件。同时还需要阅读代码结构关注是否架构发生偏离。\
对于大型软件、高可靠性要求的软件，需要给出足够上下文，因此对话框不仅输入任务要求，还需要选择函数、代码段、文件、文件夹，作为上下文。原因是大型软件，每一行代码，都有多个角度的考虑，且与其他函数、模块，有各种关联，复杂度高，因此需要给很多上下文。这类软件还是需要人工看代码，因此看代码功能还是非常关键。\
